# Atlas Solutions

Home responsive de consultoría tecnológica para almacenes. React + Vite + TypeScript.

## Ejecutar

Node.js 22.12+ o 24.

```bash
npm ci
npm run dev
npm run build
npm run lint
```

## Estructura

- src/data/content.ts: navegación, textos, capacidades y metodología.
- src/components: componentes compartidos.
- src/sections: portada, secciones y contacto.
- src/index.css: tipografía, variables y estilos globales.
- src/App.css: composición y responsive.

Lucide React para iconos, Motion para animaciones y Fontsource para fuentes locales. Movimiento reducido respetado. Estado local, responsabilidades pequeñas y contenido separado; sin capas innecesarias.

Antes de implementar: revisar librerías instaladas, evaluar alternativas y construir desde cero como última opción.
